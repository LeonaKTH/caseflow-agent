# 评测范围

公开版包含已观察的32条历史Mock任务及24条历史规则任务。Mock通过真实Agent HTTP、业务HTTP和每次独立SQLite运行，Gold在评测器侧，不输入模型。机械确认器在允许确认的任务上确认当前提案，不使用Gold替模型过滤错误提案。

32条中的dev/heldout是历史分组，已经观察，不能作为新盲测。原版曾出现用户明确部分金额却实际提交全额的负结果，可信判题捕获；后续增加语义保护和回归。当前两个Mock策略共用词法替身，该替身忽略Prompt；Mock分数不证明规划策略收益。

真实模型只完成两轮3条开发任务的冒烟，实际结果见RESULTS.md。判断成功必须核对真实业务数据库中的订单、审批与回执；模型回答“完成”不能替代账本。两组共用JSON协议、工具、受信执行器和确认审批，这不是Proposal架构消融实验。

另有24条新的独立真实评测任务已在私有开发仓库冻结，尚未运行。为避免提前泄漏任务和Gold，公开包暂不包含全部24条数据、冻结评分细节、专项执行器和依赖它们的测试。它们在原仓库完整保留；公开Mock评测与核心测试独立可运行。

新任务没有成绩，不存在可报告的真实提升。后续运行需单独授权预算，并原样保留持平、退化、工具故障、协议错误和预算中断。
